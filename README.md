# ObiKhairat Landing Page

A responsive landing page for **ObiKhairat**, a concept charity platform that connects donors of gently used essentials with families in need. Recipients only cover delivery.

**Live demo:** https://danzeem.github.io/landing-page/

![Landing page hero](screenshots/hero.png)

## About

This is the web front end for my ObiKhairat project. The main application is a Java donation-management app (the code is kept private, with a README-only showcase in the [ObiKhairat](https://github.com/danzeem/ObiKhairat) repo). This repo holds the public-facing landing page that goes with it.

It is a **front-end design concept built with HTML and CSS only**. There is no backend, and the buttons and forms do not connect to anything.

## Sections

- Navigation bar with a "Donate Now" call to action
- Hero with headline, "Donate Items" and "Request Items" buttons, and impact stats
- **How It Works:** three-step flow (List Items, Match Requests, Deliver)
- **What We Accept & How We Help:** accepted item categories plus trust, safety, and transparency points
- Community testimonials and a featured quote
- Closing call to action and footer with quick links and contact info

## Tech stack

- HTML5
- CSS3 (Flexbox and Grid layouts, gradients)

## Run locally

1. Clone the repo:
   ```bash
   git clone https://github.com/danzeem/landing-page.git
   ```
2. Open `index.html` in your browser. No build step or dependencies needed.

## Notes on content

All content on this page is **placeholder material for a design concept**:

- The stats (items donated, families helped, satisfaction rate) are made up.
- The testimonials and their names are fictional.
- The contact email, phone number, and address in the footer are dummy values.
- Features described on the page, such as automatic matching and QR proof-of-handover, are ideas for the project and are not implemented here.

The hero photo is **Kalimasada's from Crypto Academy, giving rice every week**.
